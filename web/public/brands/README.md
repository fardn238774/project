# Brand logos

Drop a brand logo here and it appears automatically on the New Cars pages.
No code or database changes needed.

## How

1. Save the logo image into **this folder** (`web/public/brands/`).
2. Name the file exactly as the brand's slug, with a `.png` (or `.jpg` / `.svg`
   / `.webp`) extension.
3. Refresh the page — the logo replaces the letter tile.

## Exact filenames expected

| Brand | File to drop here |
| --- | --- |
| Toyota | `toyota.png` |
| Honda | `honda.png` |
| Mitsubishi | `mitsubishi.png` |
| Suzuki | `suzuki.png` |

Square, transparent-background PNGs look best. If no file is present, the page
shows a clean letter tile instead — nothing breaks.
